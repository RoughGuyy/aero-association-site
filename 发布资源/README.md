# 网站正在使用的图片、字体和附件

| 本地位置 | 写进网页的地址 | 内容 |
| --- | --- | --- |
| `官网配图/照片.jpg` | `/assets/照片.jpg` | 首页与活动照片、协会标志、海报 |
| `网页字体/…` | `/fonts/…` | 首屏艺术字体与对应开源许可证 |
| `教程附件/images/…` | `/knowledge/assets/images/…` | 教程插图 |
| `教程附件/videos/…` | `/knowledge/assets/videos/…` | 制作、调试等教学视频 |
| `教程附件/files/…` | `/knowledge/assets/files/…` | PDF、模型和可下载模板等附件 |

这里是公开发布副本。原件与来源由协会内部留存，不上传到公开仓库；把照片放进内部素材库不等于已经发布。

改网页中的图片说明：去 `网站内容` 找对应正文或首页文字。若是照片上直接印着的文字，需要改图片本身，不是网页文案。

使用新照片前确认是哪次活动、是否可公开。先复制到这里，再在正文填写地址；不要直接把其他活动的照片配在具体活动报道旁。替换或删除前，在「网站内容」里搜索文件名，确认哪些页面在共用。

旧 `/assets` 和 `/knowledge/assets` 链接保持不变，目录整理不会导致已有文章图片失效。

首屏中文使用 Ma Shan Zheng，英文使用 Caveat。字体只用于首屏文字，不影响正文和导航；字仍可直接编辑。`mashanzheng-hero.woff2` 是当前首屏的快速字集，新增汉字会按需使用完整字库，不能把完整字体当成未用资源删除。发布时保留本目录下的字体文件及对应 OFL 许可证。
