# 3D 打印：X1C + AMS 快速上手

使用协会 **X1 Carbon + AMS**，从安装软件开始，完成模型准备、切片和发送打印。也可[观看操作视频](/knowledge/assets/videos/3D打印机studio示例.mp4)。

## 1. 安装 Bambu Studio

从[拓竹官网下载 Bambu Studio](https://bambulab.com/zh-cn/download/studio)，选择对应系统的安装包，安装后打开。

首次启动，按配置向导设置：

1. 登录区域选择“中国内地（大陆）”。
2. 打印机勾选 **Bambu Lab X1 Carbon，0.4 mm 喷嘴**。
3. 勾选要使用的耗材类型，如 PLA、PETG。
4. 勾选“安装 Bambu 网络插件”，完成配置。

![官方配置向导：选择中国内地（大陆）](/knowledge/assets/images/3D打印官方/setup-region.jpeg)

![官方配置向导：勾选安装 Bambu 网络插件](/knowledge/assets/images/3D打印官方/setup-network.jpeg)

## 2. 连接打印机

协会将使用公用电脑统一发送打印任务。**公用电脑启用前，请使用自己的电脑和拓竹账号临时绑定打印机。**

### 当前使用：个人账号临时绑定

1. 确认上一位同学已结束使用、打印机空闲。
2. 手机安装 [Bambu Handy](https://bambulab.com/zh-cn/download/app)，登录自己的拓竹账号。
3. 在打印机触摸屏打开 **设置 → 账号**。若仍登录上一位使用者的账号，退出后显示绑定二维码；未登录时直接查看二维码。
4. 在 Bambu Handy 中点击 **设备 → ＋ → 扫码**，扫描屏幕二维码，按提示确认绑定。
5. 电脑打开 Bambu Studio，点击“登录 / 注册”，登录同一账号。在“设备”页按现场机器选择 **令狐煊烨** 或 **空天科协**，确认能看到设备状态和 AMS 料槽。

![拓竹官方示例：扫描打印机屏幕上的绑定二维码](/knowledge/assets/images/3D打印官方/bind-qr.png)

![官方操作图：Bambu Studio 登录入口](/knowledge/assets/images/3D打印官方/login.png)

打印期间保持账号绑定。任务完成、取走零件并清理打印板后，在机器“设置 → 账号”退出自己的账号，方便下一位同学绑定。

### 公用电脑启用后

在公用电脑上打开模型或 3MF 项目，核对机型、打印板、耗材与切片预览，再发送打印。设备账号由协会统一管理，无需个人换绑。

## 3. 导入并摆放模型

### 先看懂模型是怎样打印出来的

FDM 把塑料丝加热挤出，先铺好一层，再叠下一层。层与层靠熔融塑料结合，**垂直于层面的拉力更容易把层间拉开**；悬空处没有承托，刚挤出的软塑料就可能下垂。

[观看 FDM 原理动画](#fdm-principle)

选底面时看三件事：**贴板面积大、悬空少、主要拉力尽量沿层面传递**。平整大面有助于稳定附着；调整朝向可以减少支撑，但承力件也要照顾受力方向。

### 导入与摆放

点击“新建项目”，将 **STL、STEP 或 3MF** 文件拖入“准备”页，核对模型尺寸与数量。多个零件需要独立摆放时，在“作为多零件对象导入”的提示中选择“否”。

![导入模型文件](/knowledge/assets/images/3D打印/01-import.jpg)

选中模型，点击顶部“选择底面”，再点击希望贴住打印板的平面。

![选择模型底面](/knowledge/assets/images/3D打印/03-orientation.jpg)

点击“全局整理”，让零件分开排列；确认全部位于打印区域内，互不重叠。

![全局整理模型位置](/knowledge/assets/images/3D打印/04-arrange.jpg)

## 4. 设置机型、打印板和工艺

在左侧面板依次选择：

- **打印机**：Bambu Lab X1 Carbon，0.4 mm 喷嘴。
- **打印板**：与机器上安装的板材一致；本例使用纹理 PEI 板（协会主要是光面板和纹理板，请务必对应实际情况）。
- **工艺**：先选 `0.20mm Standard @BBL X1C`。

打开下载的 3MF 项目后，也要核对这三项。

![X1C、喷嘴、打印板与工艺设置](/knowledge/assets/images/3D打印/05-machine-settings.jpg)

## 5. 同步 AMS 并指定耗材

协会常用材料：

- **PLA**：容易打印、翘边少，适合日常打印，除了特殊工程需求外，第一次建议从PLA开始；耐热较差，高温环境中容易软化变形。
- **ABS**：耐热、抗冲击，适合需要韧性和耐温的零件；容易翘边，保持机箱封闭，按板材要求涂胶，并保持房间通风。
- **PETG**：比 PLA 更韧、耐温更好，也比 ABS 容易打印；适合日常功能件，注意干燥，受潮容易拉丝。

在“设备”页确认 AMS 各料槽的材料名称与实物一致。未自动识别的料卷，点击料槽编辑材料类型与颜色（如果你不确定是什么，那就别用别管别编辑就好了，用其他确定的材料）。

返回“准备”页，点击耗材列表旁的“从 AMS 同步”。弹窗有 [匹配](https://wiki.bambulab.com/zh/software/bambu-studio/use-ams-on-bambu-studio) / [覆盖](https://wiki.bambulab.com/zh/software/bambu-studio/use-ams-on-bambu-studio) 两种方式，本例选择 **覆盖 → 立即同步**，用机器中的耗材更新项目列表，再为模型指定材料。

![从 AMS 同步耗材列表](/knowledge/assets/images/3D打印/06-sync-ams.jpg)

切换到“对象”，在模型旁的“耗材丝”列选择要使用的材料。本例选择 **PETG**。

![为模型指定 PETG 耗材](/knowledge/assets/images/3D打印/07-object-filament.jpg)

## 6. 添加支撑并切片

模型有悬空凸台或大面积悬垂时，在“工艺 → 支撑”中勾选“开启支撑”：默认先选 **树状支撑（自动）**；较大、平整的悬垂面可再比较普通支撑的效果。

[官方详解：支撑设置](https://wiki.bambulab.com/zh/software/bambu-studio/support)

点击右上角“切片单盘”，进入“预览”。拖动右侧滑条逐层查看（这个在实际使用中我其实不看，大家根据实际情况来吧），重点检查 **第一层是否完整、悬空处是否有支撑、预计耗时和耗材用量**。有悬空或越界警告时，调整模型或支撑，再重新切片。

![切片预览：右侧滑条用于逐层检查，左侧显示模型警告](/knowledge/assets/images/3D打印/08-slice-preview.jpg)

[官方详解：切片预览](https://wiki.bambulab.com/zh/software/bambu-studio/view-slicing-information)

## 7. 发送打印

确认 X1C 空闲、打印板清洁且没有遗留零件，点击右上角“打印单盘”。

在弹出的窗口中：

1. 按现场机器选择 **令狐煊烨** 或 **空天科协**。
2. 启用 **AMS**，点击耗材下方的槽位，选择装有对应材料的料槽。本例 PETG 对应 A1。
3. 本例开启 [自动热床调平](https://wiki.bambulab.com/zh/software/bambu-studio/studio-quick-start) 和 [动态流量校准](https://wiki.bambulab.com/zh/software/bambu-studio/calibration_pa)，关闭 [延时摄影](https://wiki.bambulab.com/zh/software/bambu-studio/timelapse)。
4. 点击“发送”，开始上传并启动打印任务。

![打印任务窗口：选择设备与打印前选项](/knowledge/assets/images/3D打印/09-print-dialog.jpg)

![核对耗材映射：项目中的 PETG 对应 AMS A1 料槽](/knowledge/assets/images/3D打印/09b-filament-mapping.jpg)

发送后进入“设备”页查看任务进度；加热、调平完成后，现场确认第一层正常附着。
