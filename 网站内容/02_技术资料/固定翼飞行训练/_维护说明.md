# 飞行技巧训练：内容与配图维护

技术资料页只展示两个入口：初级飞行教程和特技飞行教程。各自总览列出完整章节与简介，文章侧栏和页末导航由 `frontend/app.js` 中的 `FLIGHT_COURSES` 顺序生成。

初级总览的 id 为 `flight-training`，文件是本目录的 `00_飞行技巧训练.md`；特技总览沿用 `aerobatics-training`，文件保留在 `../安全与训练/固定翼进阶训练.md`。不要更改已发布的 id。

## 图片与导航

完整图页位于 `发布资源/教程附件/images/飞行技巧训练`。`basic-p081.jpg` 表示基础教材第 81 页，`aerobatics-p075.jpg` 表示特技教材第 75 页。各章在“教学图文”中按页顺序引用，正文图片与“查看大图”必须使用同一地址。

这批图页尺寸统一为 1516 × 1071，前端为该路径预留相同的宽高比例，并使用延迟加载。替换图片时保持尺寸，避免长页面加载过程中跳动。新增其他尺寸的插图可以放在另一文件夹，不使用这个批次的固定尺寸规则。

增删章节时同步修改所属总览、`FLIGHT_COURSES` 和维护页的覆盖表。只改文章正文无需改导航程序。原始机型设置示例保留在教材图中，正文说明其适用范围。

本地运行 `python build_static_site.py`，然后打开技术资料，确认入口仅有两套教程；进入两份总览检查章节链接，检查每套第一章和最后一章的前后导航不串到另一套。测试命令见仓库 README。
