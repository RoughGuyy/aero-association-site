修改后需要重新运行 `python build_static_site.py`，再刷新本地预览。提交 Pull Request 并合并到 `main` 后，线上网站才会自动更新。

## 修改 Markdown 正文

用文本编辑方式打开 `.md`，直接改段落、列表和小标题。例如科普页说得不合适，就改 `04_科普活动/科普活动.md` 中的对应段落。

文件最上方两条 `---` 之间是文章信息：

```text
id: moyi90
title: 魔翼 90 制作
summary: 这里是一句话摘要。
```

- 网页大标题改 `title:` 后面的文字；摘要改 `summary:` 后面的文字。
- 正文开头的 `# 标题` 不会再重复显示，最好与 `title` 保持一致。正文小标题用 `##`，小节用 `###`。
- `id` 是网页地址的识别码，不要改。`section`、`order`、`tags` 等不必为改措辞而调整。
- 新人指南部分小标题末尾有 `{#start}`、`{#aircraft}`、`{#fixed-wing}` 等。可以改它们前面的标题文字，但保留花括号内的标记；标记用于保持三种机型的排版，不会显示给访客。
- 图片写法是 `![图片说明](/assets/图片名.jpg)`。可以改方括号内的图注，圆括号内是图片地址。
- 链接写法是 `[链接显示文字](?article=moyi90)`。改显示文字时保留目标地址。对已被其他页面链接的小标题改名后，要检查对应的页内锚点。

不要把编辑意见、待核验的事实和私人信息写在正文里。正文默认公开，内部讨论不要提交到本仓库。

## 修改首页和公共文字

这两份 `.json` 把文字按页面位置列出来了，例如：

```json
"科普标题": "科普教学与活动服务",
"科普介绍": "把这段换成你希望显示的介绍。"
```

只改冒号右侧引号内的文字。保留左侧名称、双引号、逗号和括号，不要用中文引号替代英文双引号。文字里的引号建议用中文“”；每条说明是一段文字，不要直接把一个字符串拆成两行。图片地址也在首页文件中，换图前先把确认可公开的图片放入 `发布资源/官网配图`。

`{QQ群}` 和 `{安全链接}` 是自动替换标记，修改周围文字时保留标记。公共文件里的QQ群和地址会同步到页脚、首页加入区域及空通知提示，不在首屏重复展示；正文中手写的相同信息仍要另改，可在「网站内容」内搜索旧号码或旧地址。

这些文件负责现有文字，不负责添加新栏目、改变路线顺序或重排页面。新增路线章节、改变布局时再一起调整程序即可；日常改字不需要。

招新区域不再嵌入整张海报：入会文字、群号、地点和二维码直接排在网页中。二维码说明及招新群链接在首页文件中；如果换群，需要同时更换二维码和链接，不能只改显示的群号。当前二维码由原海报中的真实群链接重新编码，原海报仍保留。

首页文件中的“主视觉图片”用于首屏背景，当前为暮光羽流图。“主视觉描述”是图片替代文字；“主视觉宽度／高度”填写实际图片尺寸，当前为 2800／1260。该图有专门的桌面与手机取景样式，以后换图时需要一起检查响应式布局。CUADC 图片由“竞赛图片”单独控制，不再重复出现在首屏。首屏学校名、大标题、协会全称来自 `公共文字.json`，英文小字改首页文件的“首屏英文”。`00_首页/协会简介.md` 显示在紧接首屏的“第一次来协会”下方。艺术字仍是真实网页文字，不是图片。

项目与竞赛中的大疆海报是 CUADC 求职段落的补充材料：以 `>` 开头的一整行放在浅色说明框中，图片缩小展示，后面的原图链接供需要时查看。

## 发布新闻或通知

复制对应文件夹中的 `_template.md`，另取一个文件名，先写草稿。只有同时设置以下两项才会出现在网站上：

```text
status: published
visibility: public
```

日期、活动名称、作品归属和配图确认后再发布。只知道报道日期，不要当成活动日期。具体字段见 [新闻与通知发布说明](05_新闻与通知/_发布说明.md)。

新闻的 `summary` 是列表简介，`cover` 是配图地址，`cover_alt` 是画面说明；图片原件先归入素材库，官网使用副本放在 `发布资源/官网配图`。正文已放过封面图时，详情开头不会再重复显示。有外部报道就填写 `source_title` 和 `source_url` 等来源字段，页面会提供“查看完整报道”入口；没有链接或对应活动照片时留空。

## 文字、原始素材、问答之间的关系

- 本目录：网站正式文案。新闻列表和详情使用同一份稿件，改一次即可。
- 原始素材库：不在公开仓库中；确认事实和公开范围后，再把发布副本加入 `发布资源`。
- `发布资源`：网站实际使用的图片和附件。图片可以被不同页面共用，删除前要检查引用。

`README.md` 和以下划线 `_` 开头的说明、模板不会作为正文公开。不要直接在本目录新增没有明确用途的笔记；新增正文请沿用现有文章格式。
