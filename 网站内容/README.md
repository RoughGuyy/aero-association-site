## 哪些不是一份文件对应整页

- **技术资料首页**：[技术资料首页.md](02_技术资料/技术资料首页.md)目前只提供标题和摘要，正文没有用于页面展示。分类及入口布局由`frontend/app.js`生成；各篇教程正文仍在下表文件中。
- **活动与实践**：参与指南正文来自[活动参与说明.md](04_科普活动/活动参与说明.md)，排在活动记录之前；记录来自“活动新闻”。[科普活动.md](04_科普活动/科普活动.md)是旧栏目资料，仍由知识库加载，但修改它不会改变当前活动首页。
- **场地与公共设备**是可用的独立文章，虽然没有放在顶层导航，也不能当作空文件删除。
- 以下划线`_`开头的文件是模板、填写说明或维护说明，不是网页正文。活动通知模板暂不用于展示，但仍是模板，不是重复文案。
- 页面样式、自动目录和术语侧栏解释来自前端代码；不在Markdown正文内。

## 编辑方法

- 大标题改顶部`title:`，摘要改`summary:`，正文直接修改段落。
- 新人指南中的`{#start}`、`{#aircraft}`、`{#fixed-wing}`等是排版标记，保留标记即可自由改标题。
- 路线标题的链接、路线图片、加入协会二维码都在新人指南Markdown中。二维码写法为`[![扫码说明](/assets/图片.svg)](加群链接)`。
- `/assets/图片名`对应`发布资源/官网配图/图片名`；`/knowledge/assets/`对应`发布资源/教程附件/`。不要修改`dist`内的生成文件。
- JSON只修改右侧值，保留引号、逗号和结构。
- 修改后在项目根目录运行`python build_static_site.py`，刷新本地预览。构建不等于发布官网。
- 活动、项目、机型记录通过`status: published`和`visibility: public`控制公开状态。发布字段说明见[记录维护说明](05_新闻与通知/_发布说明.md)。
