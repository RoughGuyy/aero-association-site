# 按网页找编辑文件

这里按网页顶层导航排列：00 首页、01 新人指南、02 技术资料、03 机型目录、04 项目与竞赛、05 活动与实践。

[站点结构.json](站点结构.json)是导航和 DeepSeek 导览共用的层级来源。正文只在 Markdown 中维护；树中引用文章的 `id`，自动读取标题和摘要，不复制正文。分组节点没有独立文章；路线和课程节点有总览及下级文章。新增文章须归入树，否则构建会报错，避免出现找不到的孤立内容。

这里是网站的可编辑源文件。运行 `python scripts/preview_site.py` 后，保存内容会自动构建并刷新本地预览；发布官网仍需单独操作。

## 页面与文件的关系

- **技术资料首页**：[技术资料首页.md](02_技术资料/技术资料首页.md)只维护页面标题和摘要；重复且未显示的旧正文已移除。分组、路线和文章归属由[站点结构.json](站点结构.json)管理，前端负责布局；各篇教程正文仍在下表文件中。
- **活动与实践**：参与指南正文来自[参与指南.md](05_活动与实践/参与指南.md)，排在活动记录之前；记录来自“05_活动与实践/活动记录”。[科普活动.md](05_活动与实践/_历史资料/科普活动.md)是归档材料，不再由公开文章及导览加载；旧栏目网址仍会进入活动与实践。
- **场地与公共设备**是可用的独立文章，虽然没有放在顶层导航，也不能当作空文件删除。
- 以下划线`_`开头的文件是模板、填写说明或维护说明，不是网页正文。活动通知模板暂不用于展示，但仍是模板，不是重复文案。
- 页面样式、自动目录和术语侧栏解释来自前端代码；不在Markdown正文内。

## 索引与旧链接

- `站点结构.json` 的 `pages` 对应网站栏目，`children` 表示下级内容；`group` 是资料组，`route` 是入门路线，`course` 是完整课程。
- `references` 是跨路线参考链接，不改变文章归属。`collection` 从活动、项目或机型文件夹读取已公开记录，不逐条抄写索引。
- DeepSeek 只接收这棵树的标题、用途和 ID，不读取正文或内部资料。返回内容由程序核对，并合并同页结果、排除祖先目录与下级内容同时出现。
- `legacyRoutes` 和前端栏目别名仅兼容旧地址，不作为新增入口。`unlistedArticles` 是参与指南片段或旧文章，不单独参与导览推荐。
- `_历史资料`、`_维护说明.md`、`_template.md` 均不发布；请勿把历史资料当成当前页面编辑。

## 编辑方法

- 大标题改顶部`title:`，摘要改`summary:`，正文直接修改段落。
- 新人指南中的`{#start}`、`{#aircraft}`、`{#fixed-wing}`等是排版标记，保留标记即可自由改标题。
- 路线标题的链接、路线图片、加入协会二维码都在新人指南Markdown中。二维码写法为`[![扫码说明](/assets/图片.svg)](加群链接)`。
- `/assets/图片名`对应`发布资源/官网配图/图片名`；`/knowledge/assets/`对应`发布资源/教程附件/`。不要修改`dist`内的生成文件。
- JSON只修改右侧值，保留引号、逗号和结构。
- 在项目根目录运行`python scripts/preview_site.py`并保持运行，保存后自动更新本地预览。若只想构建一次，运行`python build_static_site.py`。两者都不会自动发布官网。
- 活动、项目、机型记录通过`status: published`和`visibility: public`控制公开状态。发布字段说明见[记录维护说明](05_活动与实践/_发布说明.md)。
