# 参与指南

## 活动通常怎样开展

1. **认识动捕实验室**：现场参观，解释实验室，认识周围的相机，了解系统怎样记录物体的位置与姿态，以及这些数据如何帮助飞行等实验。
2. **认识飞行原理**：用模型、图片和飞行视频，科普固定翼、多旋翼、直升机的飞行原理。
3. **动手制作与调试**：按当次材料选择橡皮筋滑翔机、扑翼机、电动滑翔机或木制四旋翼。带参与研学的同学完成制作。
4. **飞行与操控体验**：根据条件安排模拟器、飞行演示，或无人机足球体验。操控由熟悉设备的同学指导，飞行区与等候区分开。

## 怎样参与

会在群内发放通知，报名即可参与。一般分为主讲和助教，主讲要结合PPT，介绍实验室和科普，带领制作；助教要提前来摆放椅子，制作过程中辅助和事后收拾
