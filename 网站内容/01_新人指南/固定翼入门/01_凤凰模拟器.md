# 固定翼模拟器：选择、获取与配置

模拟器先解决三件事：认识四个主通道、飞机朝向变化时不打反舵、能反复完成起飞—航线—进近—降落。它可以和魔翼 90 制作并行，不必等飞机做好再练。

## 先选一款能用起来的

不用把所有模拟器都装一遍。电脑和遥控器能稳定识别、画面流畅，并且愿意持续练习，比追求软件数量更重要。

### Phoenix RC 6：协会现有方案

协会已有 Phoenix RC 6 安装文件、连接资料和使用经验，适合 Windows 电脑。获取方式是群文件里的“凤凰模拟器加密狗.zip”；已有实体加密狗的同学也可以直接使用。

它的优点是教程和机型够用、大家容易互相帮忙；在较新的 Windows 上如果出现启动、更新或控制器识别问题，记下出错步骤并保留报错截图，方便继续排查。

### RealFlight：付费、教程完整

- [RealFlight Trainer Edition（Steam）](https://store.steampowered.com/app/1314820/RealFlight_Trainer_Edition/)：内容更精简，适合先学固定翼基础；当前 Steam 版用于 64 位 Windows 10/11。
- [RealFlight Evolution（Steam）](https://store.steampowered.com/app/2069310/RealFlight_Evolution/)：机型、场景和后续内容更完整；当前 Steam 版用于 64 位 Windows 10/11。
- [RealFlight 官方帮助指南](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/2069310/manuals/RealFlight_Help_Guide.pdf)：控制器支持和详细设置以这里为准。

RealFlight 支持 InterLink、Spektrum WS2000/WS3000T 等控制器方案；TX12 或其他遥控器能否直连，先看它在电脑里是否被识别为 USB 游戏控制器。

### aerofly RC 10：付费、桌面平台选择较多

- [aerofly RC 10 官方购买入口](https://www.ikarus.net/en/rc10-purchase/)
- [aerofly RC 10（Steam）](https://store.steampowered.com/app/2394350/aerofly_RC_10__RC_Flight_Simulator/)
- [aerofly RC 10 官方使用手册](https://www.ikarus.net/en/rc10-manual/)

适合希望在 Windows、macOS 或 Linux 上练习的同学。购买前在官方页面核对自己的系统和控制器；普通四轴 USB 游戏控制器、模拟器遥控器或能输出 USB 摇杆信号的遥控器都可以尝试。

### 免费、轻量的选择

- [MULTIflight 官方下载页](https://www.multiplex-rc.de/en/support/software/)：Windows 免费版带一个场景和 11 个模型，适合低成本练方向和航线。
- [PicaSim 官方发布页](https://github.com/Rowlhouse/PicaSim/releases/latest)：免费、配置要求低，滑翔机和风场体验突出，也有固定翼教练机。优先从作者发布页获取当前 Windows 版本。

如果电脑性能一般，先降低分辨率、阴影和画面质量，以摇杆响应连贯、帧率稳定为准。

## 直连 USB 遥控器：先让电脑认出设备

下面这套流程用于 TX12 等直接输出 USB 摇杆信号的遥控器。InterLink、无线接收器或教练口转接线按各自说明连接；使用无线接收器时不要关闭对应射频。

1. 在遥控器里新建一个单独的 `SIM` 固定翼模型，不要覆盖实物飞机或公用遥控器里的已有模型。
2. 暂时不用混控、特殊飞行模式和复杂曲线；只做 USB 直连时，熟悉设置的同学可以关闭内置、外置射频，减少无关发射和耗电。
3. 先开遥控器，再用支持数据传输的 USB 线连接电脑；出现菜单时选择 `USB Joystick` 或同类摇杆模式。
4. Windows 可以按 `Win + R`，输入 `joy.cpl`，确认设备存在、四个摇杆轴都会变化。这里没有响应，就先换数据线、USB 口或遥控器接口，不必急着改模拟器。
5. 电脑识别正常后，再进模拟器选择设备并完成校准。校准时回中微调，让两根摇杆走满四角和全部行程。

## RealFlight 快速配置

1. 安装并启动后，打开 `Simulation > Select Controller`。
2. 选择已经识别的控制器；需要时新建一个只用于模拟器的配置文件。
3. 点击校准，让两根摇杆和准备使用的开关走满行程。
4. 进入控制器配置，依次确认油门、方向、升降和副翼。哪根摇杆移动，就让屏幕上对应通道移动。
5. 先选高翼教练机、固定地面视角和无风场景。能稳定飞航线后，再增加风、换机型或调整舵量。

如果 TX12 没出现在控制器列表，先回到 `joy.cpl` 排查；电脑都没有识别时，重装模拟器通常解决不了问题。

## aerofly RC 10 快速配置

1. 打开 `Control`，点击 `Refresh`，选中自己的控制器。
2. 进入 `Initial Setup`，按引导完成摇杆全行程和开关校准；结束前把油门杆放到中位。
3. 让软件识别四个主轴，再选择自己的摇杆模式，国内常用的是 `Mode 2`。
4. 完成后逐项检查油门、方向、升降和副翼；有一项反向，就只反向这一项。
5. 从 StepOne、PT-40 或其他 Trainer 教练机开始，使用固定观察位，先把画质调到能稳定运行。

## Phoenix RC 6 安装

参考视频：

[Phoenix 模拟器安装参考视频](https://www.bilibili.com/video/BV1Q84y1C7Ac)

群文件“凤凰模拟器加密狗.zip”解压后包含 `PhoenixRC_6.exe` 和 `PhoenixRC_emu_v0_3.zip`。协会现有安装流程是：

1. 运行 `PhoenixRC_6.exe` 完成安装。
2. 按参考视频处理安装后的 Phoenix 文件夹。
3. 有加密狗的电脑连接加密狗，再运行处理后的 `phoenixRC.exe`。
4. 启动后如果提示更新，选择否。

不同 Windows 版本出现的提示可能不一样；卡在哪一步就记下那一步，不必反复卸载重装。

## Phoenix 连接、校准和通道配置

1. 按协会现有加密狗和连接线方案，将遥控器接到电脑。
2. 运行 `launcher.exe`。
3. 选择 `Run Phoenix`，提示更新时选否。
4. 左上角进入系统设置，配置新遥控器。
5. 大小舵、油门保持等开关先放在普通位置，再按提示完成摇杆校准；提示摇杆居中时，油门也暂时放在中位，然后让两根摇杆走满全部行程。
6. 到配置文件步骤时选择 `custom`，再新建 `new profile`。
7. 选中新建的配置文件，点击“编辑配置文件”。
8. 进入“详细信息”，在控制通道表里配置固定翼常用通道。

![Phoenix 模拟器控制通道配置示例](/knowledge/assets/images/凤凰连接与使用/pdf-page-02-image-01.png)

协会现有 Phoenix 配置先按下面设置：

- `油门`：选择 `Controller channel 3`。
- `俯仰控制（升降舵）`：选择 `Controller channel 2`。
- `左右侧飞（副翼舵）`：选择 `Controller channel 1`。
- 软件里的 `尾桨控制（固定翼对应方向舵）`：选择 `Controller channel 5`。

不同遥控器输出顺序可能不同，所以最终以 `Status` 条为准：推动哪根摇杆，哪一项的状态条就应移动。其他暂时用不到的项目可以保持 `Unmapped`，比如引擎熄火/启动、收放起落架、机轮制动、大小舵量和 Panic Mode。

如果摇杆动了但状态条没动，说明通道选错了；如果状态条动了但飞机响应相反，按下一节检查后再勾选 `Invert`。

## 每次更换配置后检查方向

更换控制器、模型配置或重新校准后，都要进入模拟飞行，用小动作确认。下面是 `Mode 2` 摇杆布局：

- 左手从下往上，油门增大。
- 左手往左，机头向左偏航。
- 右手往左，飞机向左横滚。
- 右手往下，机头抬高。
- 右手往上，机头低头。

如果方向相反，只在一个地方处理反向，避免遥控器和模拟器同时反向。Phoenix 可以在对应通道勾选 `Invert`；协会现有面板也可用 `thr`、`ele`、`ail`、`rud` 对应油门、升降、副翼和方向。

## 练到什么程度

固定翼新人至少练到：

- 能平稳起飞。
- 能飞五边航线。
- 能做水平 8 字。
- 能从固定地面视角判断迎面飞来的左右方向。
- 能完成可控进近和降落，飞机朝向变化时不再频繁打反舵。

上真机前，应能在模拟器里多次稳定完成这些动作。
