# 穿越机入门：模拟器与装机

穿越机路线分两条线并行：

- **模拟器线**：用 Liftoff、VelociDrone 等模拟器练手动模式，也就是 ACRO/Rate。
- **装机线**：看 YangFPV 的 B 站内容，理解零件、装机、调试和自组机流程。

两部分可以同时学习。模拟器先把摇杆动作练成习惯，装机内容帮助你理解真实飞机为什么会这样响应。

## 模拟器怎么选、从哪里获取

先装一款即可；如果第一款和电脑或遥控器不合适，再换备选。

- [Liftoff（Steam）](https://store.steampowered.com/app/410340/Liftoff_FPV_Drone_Racing/)：付费，支持 Windows、macOS 和 Linux；教学、竞速和花飞比较均衡，适合作为通用首选。
- [Uncrashed（Steam）](https://store.steampowered.com/app/1682970/Uncrashed_FPV_Drone_Simulator/)：付费，支持 Windows 和 macOS；有简体中文，地图和画面丰富，适合花飞和自由练习。
- [VelociDrone（开发者商店）](https://www.velocidrone.com/shop)：付费，支持 Windows、macOS 和 Linux；竞速、物理和 rates 设置更深入，对电脑配置也相对友好。
- [FPV SkyDive（Steam）](https://store.steampowered.com/app/1278060/FPVSkyDive/)：基础版免费，支持 Windows、macOS 和 Linux，适合先验证电脑、数据线和遥控器能否正常工作。
- [DRL Simulator（Steam）](https://store.steampowered.com/app/641780/The_Drone_Racing_League_Simulator/)：付费，支持 Windows 和 macOS，带渐进式训练和赛道；目前更新较少，适合已有用户或作为课程型备选，不作为优先购买建议。

想尽快开始就选 Liftoff；想先零成本试通连接就选 FPV SkyDive；偏竞速训练、电脑配置一般可以选 VelociDrone；更看重中文和大场景可以选 Uncrashed。

## TX12 通用连接

协会公用遥控器里可以找 TX12。取用前检查摇杆、开关和电量，电量不足先充电，并按协会要求登记；不要覆盖其他同学的模型配置。

1. 在 TX12 里新建一个独立的 `SIM` 多旋翼模型，不要覆盖实物机或公用遥控器里的已有模型。
2. 四个摇杆通道保持线性，不在遥控器和模拟器两边重复加 expo 或曲线；把 `Internal RF` 和 `External RF` 都设为关闭。
3. 先开遥控器，再用支持数据传输的 USB 线连接。TX12 MkII 使用机身上方的 USB-C 数据口；其他版本认准机身上的 USB/Data 标识。
4. 遥控器弹出菜单后选择 `USB Joystick (HID)`，EdgeTX 先使用 `Classic` 模式；如果只出现磁盘或充电，检查接口、线材和 USB 模式。
5. Windows 按 `Win + R`，输入 `joy.cpl`。看到 EdgeTX/USB Joystick，并且四个轴都会动，再打开模拟器。
6. 进入模拟器完成它自己的控制器校准。只有在 `joy.cpl` 里出现中心点或端点明显异常时，才请熟悉遥控器的同学一起做 TX12 的 Hardware Calibration：按提示先居中，再分别沿左右、上下直线扫到端点；不要画圈，端点也不要过度用力。

飞行和摇杆响应正常时，不需要每次重新校准。电脑连接故障也不用改实物飞机的对频设置；先沿着“接口—数据线—USB 模式—`joy.cpl`—模拟器输入设备”的顺序排查。

Mode 2 的四个主轴是：

- 左杆上下：`Throttle` 油门。
- 左杆左右：`Yaw/Rudder` 偏航。
- 右杆上下：`Pitch/Elevator` 俯仰。
- 右杆左右：`Roll/Aileron` 横滚。

大多数模拟器会让你“移动对应摇杆”来映射，所以不必为了模拟器强改原有通道顺序。方向不对时只在模拟器或遥控器其中一处反向，避免双重反向。

## Liftoff 快速配置

打开 Liftoff 后：

1. 进入 `Options`，打开控制器设置。
2. 选择自己的遥控器，进入 `Calibration`，按提示让四个摇杆轴走满行程。
3. 依次确认 Throttle、Yaw、Pitch、Roll；预览方向相反时，在 `fine-tune` 里对这一轴点击 `invert`。
4. 选择第一人称视角和 `ACRO` 模式，先保留默认 rates。准备飞实物机时，再把实机的 rate 类型和数值一起匹配过去。
5. 先降低阴影、特效或分辨率，保证画面和输入稳定；穿越机练习里，稳定帧率比高画质更重要。

![Liftoff 控制设置示意](/knowledge/assets/images/liftoff连接与使用/pdf-page-01-image-02.jpg)

如果 Windows 能在 `joy.cpl` 看到遥控器，但 Liftoff 识别成普通手柄或完全没反应，可以到 Steam 的游戏属性里关闭这款游戏的 Steam Input 覆盖，再重新进入控制器设置。

## VelociDrone 快速配置

1. 从开发者商店购买后，下载并解压 launcher；登录、安装、更新和进入模拟器都从 launcher 开始。
2. 先开 TX12、选择 `USB Joystick (HID)`，再打开 VelociDrone。
3. 在 `Controller` 设置里分配 Throttle、Yaw、Pitch、Roll，完成校准和方向检查。
4. 使用真实遥控器时关闭 `Use Gamepad mode`；它是给摇杆自动回中的普通手柄准备的。
5. 新人先用默认 Rate 设置和一台常规 5 寸机练习。动作稳定后，再在软件里选择与实机相同的 Betaflight rate 类型和数值。

低配置电脑先降低画质和分辨率，保证延迟和帧率稳定；如果只练竞速路线，不必先装额外机型包。

## 其他三款的校准入口

- **Uncrashed**：进入 `Controls`，确认设备名，分配四轴后运行 `Calibration`；预览哪一轴反了，就只反向这一轴。
- **FPV SkyDive**：主菜单进入 `Joystick Calibration`，选择 `FPV Radio Transmitter`，按提示完成四轴校准；解锁前把油门归零。如果校准页完全没有输入，到 Steam 的游戏属性中把 `Controller` 设为 `Default` 后重试。
- **DRL Simulator**：先完成控制器向导，再跟训练关卡走；如果按键和旧资料不同，以当前设置页显示的绑定为准。

## 先理解 ACRO，再开始练

`ACRO`、`Rate` 和很多软件里的 `Manual` 都指不自动回正的手动模式：摇杆回中只会停止继续旋转，飞机不会自己恢复水平。`LEVEL/Angle` 会自稳，`Horizon` 是混合模式。新人可以用自稳模式认识四轴，但要尽早切到 ACRO 建立真正的穿越机操控习惯。`Airmode` 不等于 ACRO，它负责在零油门或低油门时继续提供姿态控制；模拟器提供这项设置时，准备实飞后再按实机匹配。

先在 Liftoff 的 `Button Setup` 查看并设置当前按键。协会旧资料里记录过下面这组示例；版本或自定义绑定不同时，以设置页为准：

- `A`：切换模式，屏幕左上角可看到当前模式。
- `B`：切换第一/第三人称视角。
- `V`：切换视线位置。
- `R`：重新起飞。
- `C`：切换模拟/高清图传。

## 新人练习顺序

1. 油门控制：能原地起飞，并在小范围内保持高度。
2. 平稳前进：不急着穿门，先让航线和高度可控。
3. 协调转弯：同时使用 Roll、Yaw 和 Pitch，不靠猛打单轴转过去。
4. 绕点和八字：左右两个方向都练，避免只会习惯方向。
5. 小范围穿门：速度从慢到快，撞机后能快速复位继续。
6. 姿态恢复：从抬头、低头和倾斜状态判断方向，不慌乱拉满摇杆。

先保留模拟器默认 rates，连续练几天比第一天不断改参数更有效。准备实飞后，再把模拟器的机型、相机角度和 rates 向实机靠拢。

## 装机学习：看 YangFPV

穿越机装机可以从 YangFPV 的视频开始，跟着理解零件选择、焊接、飞控设置和调试流程。

打开 B 站，搜索：

- UP 主名：`Yang_FPV`
- UID：`452575176`

主页特征：黑金色头像，简介里写有“热爱穿越机/FPV 的航模玩家”，合集里有穿越机装机教程。

看装机内容时，先关注这些问题：

- 一架穿越机通常由哪些零件组成。
- 飞控、电调、电机、接收机、图传分别负责什么。
- 焊接和走线为什么会影响可靠性。
- Betaflight 或类似飞控软件里要检查什么。
- 什么情况下绝对不能带桨调试。

## 实物调试安全

给实物机通电、解锁，或者排查电机方向、接收机和飞控设置时不要带桨。第一次装机、通电、检查电机方向或安装桨叶时，请有经验的同学一起确认；拿不准就找协会的老学长/学姐，或者直接在群里喊一声。
